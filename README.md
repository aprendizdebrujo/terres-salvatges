# Les Terres Salvatges

Un joc de rol inspirat en Old School Essentials, desenvolupat en HTML5, CSS3 i JavaScript vanilla.

## Característiques

- **Sistema de creació de personatges** simple i ràpid
- **Exploració de pobles** amb PNJs i interaccions
- **Mapa d'hexexploració** per viatjar entre regions
- **Exploració de tiles** amb monstres, tresors i combats
- **Estètica pixel art retro**

## Com jugar

Obrir `index.html` en un navegador (preferiblement amb un servidor local).

```bash
python -m http.server 8000
# o
npx live-server
```

Després accedir a `http://localhost:8000`
